Node anatomy: reference

docs/CODE_WORKSPACE_REDESIGN.md sections 2, 3 and 5. One action node design for both editors (chains add the step number), a smaller "+ Condition" in the main brain, a selectable foot on chain C-blocks, and a contextual bottom bar on phones.

1. Action node (main brain and chain)

Up to three rows: the category label (yellow), the action name on a darker green, and the description of its settings on the darkest green. Actions without settings stop after row 2. The × sits in row 1.

3. Chain C-block: header vs foot

The header and the foot are separate selection targets. Selecting the header (not a condition row) selects the If without opening any panel; adding then goes first inside the mouth. Selecting the foot (now 18 px, with a muted "end if") selects the end of the block; adding then goes directly after the whole If. Clicking a condition row opens that condition, as in the main brain.

4. Phones: tap selects, the bottom bar becomes contextual

A tap only selects (no sheet). While something is selected the bottom bar shows its actions; Edit (or a second tap) opens the config sheet. Done clears the selection and brings back the normal bar (Undo, Redo, Step, Vars, More). Same in the main brain, where Add below is replaced by Disconnect.
