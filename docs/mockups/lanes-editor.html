1. Sections with cards

Three sections: MOVEMENT, ACTIONS, VARIABLES. Each is a coloured label plus a one-line rule in muted text, no box. Tiles are coloured by action kind (Move cyan, Face violet, Ability amber, Dash teal, Cancel red). A card is one row: priority number, action tile, condition tiles, then an always-visible dashed "+ Condition"; the ⋯ menu shows on row hover (always on phones). In ACTIONS, combos are indented under their parent with a 2px left line; a follow-up has no number. Attached movement sits right after an ability tile as smaller tiles joined by a "＋" (here Fireball ＋ Back away ＋ Face enemy), added from ⋯ "Add movement while casting". A card that is off is dimmed with an "Off" label. VARIABLES shows only its label and "+" while empty.

1b. Live highlight (practice room)

While a preview runs, every card that acted this tick gets a 3px left bar in its kind colour (usually several: a Move, a Face and maybe an action). A running combo step keeps its bar while its action runs, and its parent rows show a faint bar so the whole combo path is visible.

2. Inline condition editor (opens under the row when a condition tile is clicked)

One line: what it reads, comparator (≥ ≤ =), the value. The value is a plain number box, or a reading shown with a "Num | reading" toggle when the condition compares against one (e.g. Slash range). True/false readings show a two-option toggle instead. Remove is quiet red on the right. No side panel.

3. Condition menu (opens from "+ Condition"; the button itself never changes shape)

A separate menu below the button, shifted left if it would overflow. Search is the menu's first row with no box of its own (same background as the menu) and is focused on open. Fixed height 300 px: category rail with counts on the left, one scrolling list on the right with sticky section headers. Each item is icon, short name and a muted one-line description. Typing filters live, fades empty categories, highlights the first match; ↑ ↓ Enter Esc work. The ability group is named after the card's ability. Picking an item adds the tile and opens its inline editor.

4. Card menu (opens from "+ Card" in a section, or "Add follow-up")

Same menu shell and search row. Shows only the actions that fit: for Movement the move and face actions, for Actions the abilities, dash and cancel; abilities show as the kit as big icon tiles (scrolls if many). Below: ready-made cards (one click adds a finished card). The footer shows the hovered action's stats. For "Add follow-up" it shows the Actions choices (abilities, dash, cancel). For "Add movement while casting" it shows move and face actions.

6. Inline action editor (opens under the row when the action tile is clicked)

Same shell as the condition editor. The action name with "Change" (opens the card menu to swap the action, keeping the conditions), then Target as a segmented control showing only the targets this action supports (Enemy, Me, Point, Angle; Point/Angle reveal their small number boxes), then the action's own settings as compact controls in the same row, wrapping if needed (segmented for choices, a switch for on/off, number boxes for numbers). Abilities aimed at an entity show Aim: Current | Lead | Auto (Lead reveals a seconds box); Auto is the default for projectile abilities. An ⓘ after the ability name opens the details panel (section 7). "Delete card" is quiet red on the right. Action tile labels include a short target: "Walk to enemy", "Face enemy", "Dash away"; abilities show just their name. Real ability icons sit on a dark square with a lane-coloured border (not on a solid colour fill), so every icon stays visible.

7. Details panel (ⓘ on the action editor and on ability tiles in the card menu)

A small popover anchored to the ⓘ, in the menu colours. Ability name with its icon, a one-line description, then a two-column grid of stats in mono numbers with units: damage, wind-up, active time, cooldown, range, projectile speed, stamina cost. Only stats the ability has are shown. Esc or a click outside closes it. No editing here.
