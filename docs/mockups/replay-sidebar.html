Replay sidebar (direction A, approved 2026-10-14)

The right-hand panel shown while a round replay plays, in frontend/src/replay/SimulationReplay.jsx (ReplaySidebar). It is a game surface: Chakra Petch for headings and numbers, team colours carried strongly. The end-of-match card (MatchFinishedCard) is unchanged and keeps replacing this panel once the match result is revealed. Where code and this mockup differ, the mockup wins.

  • Scoreboard on every state: Blue block left, Red block right, centre column with round number, countdown clock and "First to 2".
  • Score is the team's round wins (same value as today's roundWinsForTeam). Pips: 2 per team (wins required), filled per win.
  • Names: every participant of the team on its own line, never truncated (20-character names wrap). The viewer's name gets a "You" chip. With no names, show "Blue team" / "Red team".
  • Round shows as a plain number ("2"), never "2/3". The clock is the existing countdown (replaySeconds), amber.
  • Exactly one state card under the scoreboard (states below). "Leave replay" is a quiet secondary button at the bottom (it replaces the fuchsia button at the top; same handler and label prop).
  • No per-bot HP or abilities here: the canvas status panels already show them.
